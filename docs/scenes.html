Same agents, cloud or laptop

The call

  • Strands BidiAgentLive Hindi voice
  • Amazon Nova SonicSpeech to speech on Bedrock
  • Twilio bridge8 kHz phone audio, ready for a number
  • Red flags in codeBefore any model acts

The agents

  • Strands Graph with a cycleEvidence, then a custom verifier node
  • Strands interrupts in a hookA durable pause until a vet decides
  • Two model familiesNova 2 Lite reasons, Llama 3.3 checks
  • AgentCore RuntimeHosts all of it, deployed on AWS
  • Local model through OllamaWhen there is no signal

The tools

  • 7 MCP serversThe same contract in both lanes
  • AgentCore Gateway + CedarDefault deny, checked outside the model
  • Ed25519 signaturesVerified inside each tool
  • S3 Object LockSeals the signed record
